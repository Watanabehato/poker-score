# 桌边 · 德州扑克逐手牌桌

零依赖静态网站：https://watanabehato.github.io/poker-score/

用于现场发牌时的牌桌管理：按顺时针座位添加玩家，选择首位庄家和大小盲，开始每手时自动扣盲注。提示当前行动玩家，记录弃牌、过牌、跟注、下注/加注和全下，自动推进翻牌前、翻牌、转牌、河牌及摊牌。两人桌自动使用庄家兼小盲的顺序，零筹码玩家跳过。

摊牌后现场比牌并选择底池赢家，平局可多选。自动拆分主池和边池，未被跟注的筹码退回，无法均分的余数筹码从庄家左侧起顺时针分配。默认在结算后自动轮庄并开始下一手；准备结束整场时取消勾选自动开始。每手结果计入当前筹码与整场输赢。

页面包含十种牌型的扑克牌示例、大小顺序、同牌型比较、踢脚、A2345顺子和共享公共牌的平局说明。规则适用标准52张无上限德州扑克。网站不发虚拟牌，不识别现场牌面，不提供多人设备实时同步。

保留买入、增购、直接计分、多场牌局、撤销、JSON备份和整场结算复制。数据保存在当前浏览器；旧版数据和备份兼容。旧牌局若未录入筹码，可在开局前使用「按买入初始化筹码」；此按钮覆盖当前筹码，会先提示确认。进行中的每手也会自动保存，刷新可恢复；撤销历史仅限本次页面打开期间。

## 发布

GitHub Pages 选择 Deploy from a branch、main 分支、/(root)。无构建步骤，.nojekyll 禁用 Jekyll。

## 验证

运行 node test.cjs 验证整场结算；node test-table.cjs 验证逐手行动、轮庄、两人盲注、加注权、全下边池、余数筹码及500手模拟的筹码守恒。
