# 桌边 · 德州扑克计分

零依赖静态网站，适用于 GitHub Pages。支持玩家管理、买入与增购、最终筹码、直接加减分、平衡校验、转分建议、多场牌局、撤销、JSON备份和结算复制。数据仅保存在当前浏览器，不提供多人实时同步。

## 发布

创建公开仓库 `poker-score`，将本目录的文件上传到仓库根目录。在 Settings → Pages 中选择 Deploy from a branch、main 分支、/(root)，保存即可。

## 使用

筹码模式添加玩家时自动记录默认买入，结束时输入每人最终筹码，合计平衡后显示结算建议。直接计分模式通过正负整数记录每轮得分。增购和记分都可以撤销。换设备前先导出备份。

## 验证

运行 `node test.cjs` 验证结算计算。
